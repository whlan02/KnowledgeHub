# Notion 单页功能清单与落地方案

来源:Notion 官方帮助文档(writing-and-editing-basics、keyboard-shortcuts、customize-and-style-your-content、transforming-content-blocks)。

原则:文件始终是普通 Markdown,能用标准语法的就用标准语法,必须扩展的再用自定义标记。

## 1. 块手柄(截图里的那个)

| Notion 功能 | 说明 | 本项目 |
|---|---|---|
| `+` | 悬停某行时出现在左侧,点开块类型菜单,在下方插入 | 做 |
| `⋮⋮` 拖动 | 拖动移动块,蓝色线提示落点,可嵌套进列表 | 做 |
| `⋮⋮` 点击 / `Ctrl+/` | 打开块菜单 | 做 |
| 悬停提示 | "拖动移动 / 点击或 Ctrl+/ 打开菜单" | 做 |

块菜单项:

| 菜单项 | 本项目 |
|---|---|
| Turn into(转换类型) | 做 |
| Color(文字色 / 背景色) | 做,语法见第 5 节 |
| Duplicate(复制一份) | 做 |
| Delete | 做 |
| Copy link to block | 做,复制 `笔记路径#标题` 形式的链接(仅标题块有稳定锚点) |
| Move to(移到别的页面) | 后做 |
| Comment / Suggest edits / Ask AI | 不做(协作和云端功能) |
| 字数统计 | 后做 |

## 2. 块类型

| 块 | Markdown 写法 | 状态 |
|---|---|---|
| 正文、H1–H3 | 标准 | 已有 |
| 无序 / 有序列表、待办 | 标准 | 已有 |
| 引用 | `>` | 已有 |
| 代码块 | 围栏 | 已有,缺语言选择 |
| 分隔线 | `---` | 已有 |
| 表格 | GFM | 已有,缺行列操作 |
| 折叠块(Toggle)、折叠标题 | `<details><summary>` | 做 |
| 提示块(Callout) | GitHub 的 `> [!NOTE]` 等 | 做,图标只能用预设几种 |
| 公式 | `$…$` / `$$…$$` | 后做 |
| 书签 | 普通链接 | 后做 |
| 子页面 | 指向另一个 `.md` 的链接 | 随新建笔记一起做 |

| 分栏(Columns) | Markdown 无对应 | 最后,可能不做 |
| 数据库、同步块、按钮、面包屑 | 无 | 不在单页范围 |

## 3. 斜杠菜单 `/`

- 输入 `/` 弹出菜单,继续输入过滤,`Esc` 关闭。
- 列出块类型(`/bullet`、`/heading`),也有动作(`/delete`、`/duplicate`、`/turn`)和颜色(`/red`)。
- 顶部显示最近使用的。

## 4. 选中文字的浮动工具栏

- 样式:加粗、斜体、**下划线**、删除线、行内代码、链接。下划线 Markdown 里没有,用 `<u>`。
- 「转换类型」下拉、「A」文字颜色 / 高亮下拉。
- 评论、@ 提及、AI:不做(@ 提及页面可以后做成笔记链接)。

## 5. 颜色(已定:方案 B,自定义标记)

Notion 的颜色集:默认、灰、棕、橙、黄、绿、蓝、紫、粉、红,文字色和背景色各一套。

| 用途 | 写法 |
|---|---|
| 文字色 | `{red}文字{/red}` |
| 背景色 | `{bg-yellow}文字{/bg-yellow}` |
| 整块颜色 | 把整块内容包进上面的标记里 |

颜色名取 `gray brown orange yellow green blue purple pink red`。`Ctrl+Shift+H` 重复上一次用过的颜色。

## 6. 快捷键

| 类别 | 键 |
|---|---|
| 格式 | `Ctrl+B` 加粗,`Ctrl+I` 斜体,`Ctrl+U` 下划线,`Ctrl+Shift+S` 删除线,`Ctrl+E` 行内代码,`Ctrl+K` 链接 |
| 转换 | `Ctrl+Shift+0` 正文,`1/2/3` 标题,`4` 待办,`5` 无序,`6` 有序,`7` 折叠,`8` 代码块 |
| 选中块 | `Esc` 选中当前块,方向键移动,`Shift+↑/↓` 扩选,`Shift+点击` 范围选,`Alt+Shift+点击` 增减,`Enter` 回到编辑 |
| 移动 | `Ctrl+Shift+↑/↓` |
| 复制 | `Ctrl+D`,拖动时按住 `Alt` |
| 缩进 | `Tab` / `Shift+Tab` |
| 菜单 | `Ctrl+/` 打开块菜单 |
| 折叠 | `Ctrl+Alt+T` 展开 / 折叠所有折叠块 |

行首 Markdown 快捷输入:`* - +` 无序,`[]` 待办,`1.` 有序,`# ## ###` 标题,`>` 折叠,`"` 引用,`---` 分隔线。行内:`**` `*` `` ` `` `~`。这部分 TipTap 多数自带。

## 7. 多块选择

- 从页面左右边距拖拽框选整块。
- 跨块选择部分文字。
- 选中块后显示字数。

## 8. 页面外观(右上角 Appearance)

字体(默认 / 衬线 / 等宽)、小字号、全宽。属于页面设置,放到最后。需要的话存到 frontmatter。

## 开发顺序

1. **块手柄**:`+`、拖动、块菜单(转换类型、复制、删除)。**已完成**,同时加了 `Ctrl+/`、`Ctrl+D`、`Ctrl+Shift+0~8`。
2. **斜杠菜单**和**浮动工具栏**,补齐快捷键。**已完成**(下划线存成 `<u>…</u>`,`Ctrl+K` 编辑链接)。
3. **块选择**与键盘移动、缩进、右键菜单。**已完成**(缩进只对列表项有效,见 `docs/issues.md`)。
4. **颜色**(自定义标记的解析 / 序列化 + 菜单 + 重复上次颜色)。**已完成**:工具栏、块菜单、`/red` 命令、`Ctrl+Shift+H`。
5. **新块类型**:折叠块、提示块、下划线。
6. 代码块语言、表格行列操作、公式、书签。
7. 页面外观。
