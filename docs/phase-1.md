# 阶段 1：直接编辑

这一阶段只改正在看的那一页：点进正文就能写，选中文字出现格式菜单，输入 `/` 能插入块，改动自动写回 `.md`。

磁盘上继续是普通 Markdown。示例笔记会在首次启动时复制到 Documents/KnowledgeHub，和其他笔记一样可编辑。

## 做到什么

- 桌面应用直接读写工作区文件夹，不再需要浏览器授权。
- 正文是所见即所得编辑器（TipTap + Markdown 序列化），不设单独的「编辑」按钮。
- 选中文字后，选区旁出现：加粗、斜体、删除线、行内代码、链接。
- 空行输入 `/`，可插入：正文、一到三级标题、无序/有序列表、待办、引用、代码块、分隔线。
- 停止输入约 400ms 后写回当前笔记。保存期间暂停目录扫描，避免刚写完又被读回来覆盖。
- 空文档提示「输入 / 插入内容」。快捷键覆盖 Ctrl+B、Ctrl+I、撤销、重做。
- 链接、图片、待办、表格能读进来再写回去。保存可以重排空格和列表符号。

## 先不做

块左侧把手、拖拽排序、整块选中、新建/重命名/删除笔记、搜索。

## 落地顺序

1. 读写权限和保存。（已做）
2. 正文按渲染后的页面直接改，并自动保存。（已做）
3. 选中菜单。
4. `/` 菜单。
5. 核对链接、图片、待办、表格的往返。
