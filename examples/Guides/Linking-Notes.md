# Linking Notes

Relative Markdown links work across files in the same notes folder.

## Example

From this file you can jump back to the intro:

- [Getting Started](../Getting-Started.md)
- [Examples home](../README.md)

## Tips

- Prefer paths like `./note.md` or `../folder/note.md`
- Folder links such as `./Guides/` resolve to that folder's `README.md` when present
- In-page anchors (`#heading-id`) still work for the current document
