# Getting Started

KnowledgeHub is a local Markdown reader.

## What it does

- Scans a folder for `.md` files
- Shows them in a sidebar tree
- Renders Markdown in the main pane
- Builds a floating table of contents from headings

## Try this

1. Click **Open folder** and select any directory of notes.
2. Use the left sidebar to open another file.
3. Hover the thin markers on the right edge to open the page TOC.
